# MediLink AI – Emergency Healthcare Locator

## Overview
MediLink AI is a healthcare accessibility project designed to make emergency medical assistance easier to access. The platform includes an SOS feature that helps patients connect with nearby government hospitals during emergencies.

## Problem Statement
Accessing emergency medical assistance quickly can be challenging, particularly when patients need to locate nearby government healthcare facilities. MediLink aims to simplify this process through an accessible emergency assistance platform.

## Key Features
- Emergency SOS functionality
- Nearby government hospital connection
- Custom map functionalities
- Emergency assistance workflow
- Healthcare accessibility focus

## Technology Stack
- Python
- Flask
- Flask-CORS
- SQLite
- Map API

## Project Context
Developed collaboratively as part of an 8-hour hackathon by a team of four.
